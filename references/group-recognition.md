# 群体与认同分析

目标是准确识别共同处境与表达缺口，不是替群体编造心声或迎合情绪。

## 划分群体

优先使用：

```text
共同场景 + 共同约束 + 共同损失 + 共同期待
```

人口属性只有在会改变经历或行为时才加入。避免“年轻人”“女性”“创业者”等过宽标签。

## 标记证据等级

- **已观察**：来自评论、访谈、调查、行为或统计材料。
- **已报告**：由用户、当事人或可靠来源明确提供。
- **合理推断**：由处境和行为推导，尚未验证。
- **未知**：当前没有材料。

没有现实材料时，使用“待验证群体假设”，不得使用“大多数人都认为”等确定措辞。

## 建立群体地图

按需分析：

- 共同经历：反复发生的具体处境；
- 事实共识：群体相信发生了什么；
- 解释共识：群体相信为什么发生；
- 情绪共识：共同的委屈、焦虑、不甘、希望或自豪；
- 身份共识：他们认为“我们是什么人”；
- 内部分歧：不同资源、阶段和角色造成的差异；
- 认知冲突：口头相信的解释与实际经验冲突；
- 身份冲突：希望成为的人与现实位置冲突；
- 表达缺口：经历广泛存在，但缺少准确、可认领的语言。

## 区分三种反应

### 被说出来

来自高频共同经历、准确命名和孤立感解除。核心问题是“这是否准确描述了我的处境”。

### 你说得对

可能来自经验吻合、解释可信、立场一致或表达精准。分别标明，不把立场认同当事实证明。

### 还想继续看

来自未来解释价值：相邻问题仍然存在，作者表现出稳定判断方式，用户预期继续获得相关且可信的解释。

## 廉价认同审计

检查候选观点是否：

- 无证据地替整个群体发言；
- 把群体愿望当作事实；
- 制造虚假共同敌人；
- 免除群体全部责任；
- 把复杂问题归因于单一恶意主体；
- 用“只有我们清醒”的身份优越感换取认同。

若主要依赖这些机制，标记为“廉价认同风险高”，不得把它包装成群体洞察。

## 最小输出

```text
【群体定义】
【材料与证据等级】
【共同处境】
【共识与内部差异】
【认知或身份冲突】
【表达缺口】
【可能触发的反应及原因】
【廉价认同风险】
【仍需验证什么】
```
