# 学科镜头路由

学科是提问与检验工具，不是最终裁判。先找解释缺口，再选最少的互补镜头。

## 选择协议

1. 写出尚未回答的子问题。
2. 判断缺口属于语言、事实、个体、互动、结构、传播或决策层。
3. 选择能够增加新变量、竞争解释或验证方法的镜头。
4. 说明镜头的贡献、证据要求和边界。
5. 若两个镜头只是换术语重复同一结论，删除其中一个。

## 镜头表

| 解释缺口 | 可选镜头 | 主要增加的变量 | 常见误用 |
|---|---|---|---|
| 词义、命题和推理不清 | 逻辑、语言哲学、概念分析 | 定义、前提、必要与充分条件、论证关系 | 把现实冲突误当语言问题；强求唯一“本质” |
| 事实是否发生、叙述是否可信 | 新闻学、历史学、统计学 | 信源、时间线、样本、基准率、缺失事实 | 用单个故事代替总体；把报道框架当事实本身 |
| A是否导致B | 因果推断、统计学、实验方法 | 对照、反事实、混杂变量、选择偏差 | 把相关性、先后顺序或成功者自述当因果 |
| 个体为何注意、相信或行动 | 认知心理学、动机心理学、行为经济学 | 注意、记忆、预期、损失、自尊、动机 | 读心；用心理标签替代行为证据 |
| 人与人如何互相影响 | 社会心理学、博弈论 | 身份、规范、从众、信号、策略回应 | 忽略制度与资源差异；假设参与者完全理性 |
| 群体为何处于不同位置 | 社会学、人类学、制度经济学 | 阶层、角色、社会资本、规则、权力、本土意义 | 用结构抹去个人差异；用少量访谈代表总体 |
| 资源、利益和交易如何运作 | 经济学、行为经济学、博弈论 | 激励、机会成本、价格、风险、信息不对称 | 把价格当全部价值；忽略权力和非市场关系 |
| 系统为何长期强化或反转 | 系统科学、复杂系统、网络科学 | 反馈、延迟、瓶颈、路径依赖、网络效应 | 画出回路就假装证明因果；忽视可测量证据 |
| 观点为何被看见和传播 | 传播学、网络科学、平台研究 | 框架、议程、媒介环境、节点、扩散机制 | 用传播成功证明内容真实；忽略平台与偶然性 |
| 词语和符号为何有身份力量 | 符号学、话语分析、文化研究 | 隐喻、标签、叙事、命名权、身份边界 | 把所有表达都解释成权力阴谋 |
| 用户为何选择、购买或留存 | 产品研究、营销、消费者行为 | 使用场景、替代方案、风险感知、选择阻力 | 用口头偏好代替实际行为；把转化等同长期价值 |
| 下一步怎样选择和验证 | 决策科学、实验设计 | 目标、标准、可逆性、信息价值、停止条件 | 把价值取舍包装成客观最优 |

## 每次调用的最低说明

```text
【镜头】
【回答的子问题】
【新增变量或关系】
【可反驳预测】
【需要的证据】
【解释边界】
```

命理等非实证体系不得作为事实因果裁判。可把它作为象征、叙事、心理投射或社会实践来研究，并明确其证据等级。
